# 存储模型

## 职责矩阵

| 存储 | 保存 | 不保存 |
| --- | --- | --- |
| GitHub/Git | 代码、已发布 Blog/Knowledge/Project/Friends、公开元数据、迁移与文档 | 草稿、明文密钥、访客私有提交 |
| Local SQLite | 草稿、编辑/研究状态、未发布批注、任务与配置引用 | 1Password 主密码、长期密钥明文 |
| Local media root | 原始媒体、AI 生图原件、处理中间文件、派生缓存 | 无索引的散乱临时文件 |
| Public WebDAV | 音乐、公开文档、Vault、大型公开资源 | 管理凭据、未发布内容 |
| Collection WebDAV | 按提交隔离的访客资料 | 公共目录列表、跨访客可读历史 |
| Security WebDAV | 加密灾备包与非敏感 manifest | 明文快照、动态密钥 |
| 1Password | AI/WebDAV/GitHub/Cloudflare 等凭据、TOTP、备份密钥 | 内容正文、媒体、普通配置 |

## 路径与身份

- 所有内部对象使用稳定 ID；用户可见 slug/文件名只是属性。
- 授权前先 URL decode、规范化路径并处理 `..`、`.`、大小写、分隔符和符号链接边界。
- 不用字符串前缀判断“是否在允许目录内”。
- 远端对象写入采用临时名 → 完整性验证 → 原子/等价提交，能力不支持时记录降级方案。

## 媒体保留

- 本地 original 是归档源；派生图可重建。
- 公共对象可能被外链，删除需先做反向引用审计并进入可恢复隔离期。
- GPS EXIF 默认从公开派生物移除；原件是否保留由 Owner 设置。

## 容量与清理

- 在实际媒体规模与供应商限额验证前，不冻结容量阈值。
- 清理任务必须 dry-run、显示目标、引用和可恢复性；不得把未引用等同于可立即删除。

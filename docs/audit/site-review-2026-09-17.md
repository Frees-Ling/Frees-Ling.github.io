而且不止文案问题：

- 页面标题在 1440px 下断成三行，最后一行只剩「西。」两个字

### ✓ 成立：`blog/transformer/` 是真正的重量级页面

| 指标 | 数值 |
| --- | --- |
| HTML | **1412 KB**（gzip 后 248 KB） |
| DOM 节点 | **31,753** |
| 代码块 | 174 个 |

| 4× CPU 降速下的 load | 4.7 s |

## 三、搜索与长文阅读的功能验证

### 搜索（真实浏览器，Pagefind）

| 查询 | 结果 |
| --- | --- |
| `注意力`（二字中文） | 10 条 |
| `矩阵` | 3 条 |
| `标注` | 8 条 |
| `线性代数` | 2 条 |
| `Python` / `YOLO` / `Transformer` | 10 / 5 / 2 条 |
| `麻将`（确实没有） | **0 条，显示「没有找到 麻将 相关内容」** |

三种状态**互相可区分**，这正是要求里最要紧的一条：

1. **空查询** → 只显示输入框，不显示任何「没找到」文案
2. **索引加载失败**（拦截 pagefind 资源复现）→ 显示专门的说明：
   「搜索索引将在网站构建完成后启用。你仍然可以先浏览 文章归档。」
   并给出替代路径
3. **真的没有匹配** → 「没有找到 X 相关内容」

控制台错误：0。

**一个已知行为**（不是缺陷，但值得记录）：Pagefind 对最后一个词做**前缀匹配**，
所以 `qqqqqq` 会命中代码里的 `XW_QQ`、`xyzzynotaword` 会命中矩阵里的 `xy`。
对个人站这是有用的（打 `trans` 能找到 Transformer），代价是长垃圾串可能返回
一条边缘结果。

### 长文阅读

- 目录：`transformer` 走分组折叠路径（652 个标题 → 按章节折叠）
- 右侧目录跟随当前章节的脚本在 `[...slug].astro` 里，依赖 `IntersectionObserver`
- KaTeX 公式：496 个可横向滚动的公式块，**只给真正溢出的加 `tabindex`**
  （全加会产生 496 个 Tab 停靠点，比原问题更糟）
- 无横向溢出（浏览器门禁在 7 个视口 × 17 条路由上确认）

## 四、本次实际完成的代码修改

### 1. 项目页（`src/data/site.ts` + `src/pages/projects.astro`）

- 眉标 `PROJECTS · BUILDING IN PUBLIC` → `项目`
- 标题缩短，从三行断行改为两行（1440px 与 390px 均已核对）
- **每张卡片接入真实入口**：关联文章按 slug 链到 `/blog/…/`
  - Frees Blog → 1 篇、Computer Vision Notes → 4 篇、Robotics Playground → 1 篇
  - Mahjong AI → **如实说明「还没有写成文的工作记录」**，不编造
- **仓库状态如实标注**：`公开仓库`（附真实地址）/ `仓库待确认` / `尚未开源`
  - 只有从 `git remote` 能核实的才写地址；其余一律不写，也不拿 `#` 或首页冒充

### 2. 外链 `rel` 属性（6 个文件，7 处）

`rel="noreferrer"` → `rel="noopener noreferrer"`。
`noreferrer` 在现代浏览器里蕴含 `noopener`，但显式写出两者是明确要求，
也让审计规则可机械检查。当前站全部合规；`dist/history/` 的旧站归档**未改动**。

### 3. 新增 `scripts/check-projects.mjs`（`npm run check:projects`）

三类断言，**已做突变验证**（改坏 slug、把地址换成 `#`，两条都会红）：

1. 关联文章的 slug 在 `dist/blog/` 里真实存在
2. 仓库地址格式合法且**不是占位符**（`#`、空串、首页地址都算冒充）
3. `repoStatus` 与实际有没有 `repo` 一致

**不在构建闸门里做联网可达性检查** —— 构建必须能断网完成
（见 `npm run check:offline`），把网络请求塞进来会让「能不能发版」
取决于 GitHub 那一刻的可用性。

## 五、修复过程中抓到的自身缺陷

1. **我新增的 CSS 用了不存在的 token**（`--dur-fast`、`--ease`）——
   被 `check:tokens` 拦下。这正是那条闸门存在的理由：CSS 变量引用未定义时
   **完全不报错**，属性静默失效。项目实际用的是裸 `140ms ease`，已按既有约定改。

2. **Bash 钩子拦截了只读检查** —— 我执行
   `git status --porcelain public/history`（纯读取）时被拒绝，因为命令文本里
   出现了归档路径字面量。这是 PENDING-001 记录的自阻塞问题的又一次实例。

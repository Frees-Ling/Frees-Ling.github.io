# Frees Blog 历史归档

这里集中保存已经退出当前网站运行流程、但仍有历史价值的项目资料。

## 归档分类

### `sites/Frees-Blog`

- 类型：旧版个人博客完整源代码
- 状态：只读历史归档，不参与当前网站构建
- 内容：旧主题、页面结构、配置、公开资源及 17 篇原始文章
- 现站入口：`/history/`
- 第一版展品：`/history/v1/`，来源于 `sites/Frees-Blog/存档/index.html`
- 第二版展品：`/history/v2/`，由 `sites/Frees-Blog` 的 Astro 源码生成
- 文章现址：`src/content/posts/`

当前网站的正式源代码直接位于仓库根目录。归档项目用于回看旧版设计与实现，不应在这里继续开发新功能。可公开浏览的历史快照保存在 `public/history/`，因此部署当前网站时不需要重新安装或构建旧工程。历史快照只对缺失资源、失效路径和搜索隔离做兼容处理，原始归档源码不改动。
